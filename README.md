# alienmuse.github.io

The website of Vincent Liu (WiseMotif.ai): <https://alienmuse.github.io>

Its first collection is **The Grothendieckian Programme** — Series 00–07 of the WiseMotif Monograph of Mathematical
Intelligence: the overview and the seven works, each with its DOI, its repository and its boundary in its own words.
Repository of the Programme: <https://github.com/AlienMuse/grothendieckian-programme> · Zenodo community:
<https://zenodo.org/communities/grothendieckian-programme>

This repository holds the built site: static HTML and CSS, in English and Chinese, with no script and no external
request. Every text about the works is taken from the works themselves, their Zenodo records and the Programme
repository. Corrections: the [errata form of the Programme
repository](https://github.com/AlienMuse/grothendieckian-programme/issues/new?template=errata.yml).
